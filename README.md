# PortHostScan

## Description
PortHostScan is a fast, lightweight port and host scanner designed for network discovery and port enumeration in security assessments and reconnaissance workflows. Built with portability and automation in mind.

## Features
- Fast host discovery and TCP port scanning.
- Parallel scanning with configurable concurrency.
- Supports custom port lists and common port presets.
- Output in plain text and CSV for automation and integration.
- Optional integration with `nmap` for deeper service/version detection.
- Designed for use in scripts and forensic/network assessment pipelines.
